# Лабораторная работа №2

## Задание
Разработать многостраничный web-сайт на произвольную тему с использованием технологий HTML и CSS.

## О сайте
Многостраничный веб-сайт **«MIND / FIELD – Природа сознания»**, представляющий собой мини-справочник по ключевым философским теориям сознания.

## Структура

```text
lab2/
├── images/
│   └── mind-orbit.png     # Картинка в проекте
├── index.html             # Главная страница
├── materialism.html       # Раздел 01: Материализм
├── dualism.html           # Раздел 02: Дуализм
├── idealism.html          # Раздел 03: Идеализм
├── panpsychism.html       # Раздел 04: Панпсихизм
└── style.css              # Общая таблица стилей
```

## Выполненные требования:
- **Структура:** 5 страниц с единой навигационной цепочкой;
- **HTML:**  блочные и строчные элементы, навигационные ссылки, изображение, таблица;
- **CSS:** отдельный подключаемый файл, >3 видов селекторов, переменные цвета;
- **Таблица:** 3 вида выравнивания текста в столбцах (влево, по центру, вправо);
- **Ограничения:** выполнено без JavaScript, Bootstrap и сторонних библиотек.
