# Лабораторная работа №2

## Задание
Разработать многостраничный web-сайт на произвольную тему с использованием технологий HTML и CSS.

## О сайте
Многостраничный веб-сайт **«MIND / FIELD – Природа сознания»**, представляющий собой мини-справочник по ключевым философским теориям сознания.

## Структура

```text
lab2/
├── images/
│   └── mind-orbit.png     # Картинка в проекте
├── index.html             # Главная страница
├── materialism.html       # Раздел 01: Материализм
├── dualism.html           # Раздел 02: Дуализм
├── idealism.html          # Раздел 03: Идеализм
├── panpsychism.html       # Раздел 04: Панпсихизм
└── style.css              # Общая таблица стилей
```

## Выполненные требования:
- **Структура:** 5 страниц с единой навигационной цепочкой;
- **HTML:**  блочные и строчные элементы, навигационные ссылки, изображение, таблица;
- **CSS:** отдельный подключаемый файл, >3 видов селекторов, переменные цвета;
- **Таблица:** 3 вида выравнивания текста в столбцах (влево, по центру, вправо);
- **Ограничения:** выполнено без JavaScript, Bootstrap и сторонних библиотек.

# Лабораторная работа №4

## Задание
Модернизация web-сайта из лабораторной работы №2 с использованием современного CSS и основ ООП на JavaScript.

## О сайте
Обновлённая версия справочника **«MIND / FIELD – Природа сознания»**: вёрстка разделена на Grid и Flexbox, все цвета вынесены в CSS-переменные, добавлена CSS-анимация, страница с формой и обработка данных на JS через класс, а классы переведены на методологию БЭМ.

## Структура

```text
lab4/
├── images/
│   └── mind-orbit.png     # Схема для главной страницы
├── index.html             # Главная страница (вёрстка на Grid + CSS-анимация)
├── materialism.html       # Раздел 01: Материализм
├── dualism.html           # Раздел 02: Дуализм
├── idealism.html          # Раздел 03: Идеализм
├── panpsychism.html       # Раздел 04: Панпсихизм
├── auth.html              # Раздел 05: Страница с формой (вёрстка на Flexbox)
├── script.js              # Класс SubscriptionRequest и валидация формы
└── style.css              # Стили по БЭМ (все цвета через CSS-переменные)
```

## Выполненные требования:
- **Flexbox и Grid:** главная страница `index.html` свёрстана на CSS Grid, страница формы `auth.html` — на Flexbox;
- **Цвета:** все цвета заданы через CSS-переменные в `:root`;
- **Анимация:** реализована CSS-анимация `@keyframes scanWave` для схемы на главной странице;
- **Форма:** на странице `auth.html` реализовано 4 типа полей (`text`, `password`, `select`, `checkbox`) и кнопка отправки, добавлена базовая валидация;
- **ООП на JS:** создан класс `SubscriptionRequest` с конструктором и методом `printFormatted()` для форматированного вывода объекта в консоль при отправке формы;
- **Бонус:** использована методология БЭМ.
